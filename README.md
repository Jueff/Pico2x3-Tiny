# PicoServo-ATTINY

(deutsche Version weiter unten)

Brief description
----------------
This project contains firmware for the Raspberry Pi Pico that emulates a 3× sound and 3× servo controller for MobaLedLib-based model railway setups. The firmware receives LED data, controls up the sound modules and servos (in two groups) and provides status feedback via addressable LEDs. Configurations (sound module type, limits, speed, position) are stored in flash.

Key features
------------------
- Control of 3 sound modules and 3 servos
- Persistent storage of parameters in flash
- Interactive configuration modes (Min/Max, Speed)

---

Kurzbeschreibung
----------------
Dieses Projekt enthält Firmware für den Raspberry Pi Pico, die einen 3×-Sound- und 3×-Servo-Controller für MobaLedLib-basierte Modelleisenbahnanlagen emuliert. Die Firmware empfängt LED-Daten, steuert die Soundmodule und Servos (in zwei Gruppen) an und liefert Statusrückmeldungen über adressierbare LEDs. Konfigurationen (Soundmodultyp, Grenzwerte, Geschwindigkeit, Position) werden im Flash-Speicher abgelegt.

Hauptmerkmale
------------------
- Steuerung von 3 Soundmodulen und 3 Servos
- Permanente Speicherung der Parameter im Flash-Speicher
- Interaktive Konfigurationsmodi (Min/Max, Geschwindigkeit)
